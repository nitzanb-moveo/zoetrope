# מחולל הזואטרופ

כלי לבניית אנימציית זואטרופ מסדרות דימויים — טבעת מסתובבת עם תריסים,
בדיוק כמו צעצוע האנימציה מהמאה ה‑19.

**👉 [לפתיחת הכלי](https://REPLACE-ME.github.io/zoetrope/)**

נבנה עבור פרויקט בית אבי חי · Moveo

---

## מה הוא עושה

- **מעלים סדרת דימויים** (SVG או PNG) והם נפרשים סביב טבעת
- **תריסים / סטרובוסקופ** יוצרים את אשליית התנועה
- **כמה סדרות ברצף** — כל אחת מקבלת הקפה, והמעבר ביניהן קורה מאחורי הגליל
  כך שלא רואים אותו
- **אנימציה פנימית** — כל דימוי יכול להיפתח או לזוז בתוך עצמו

## מה אפשר לייצא

| | |
|---|---|
| **וידאו** | WebM · ייצוא מדויק, בלי ריצוד, בלי תלות במהירות המחשב |
| **רצף תמונות** | PNG או WebP, עם שקיפות — לאפטר אפקטס וכלי עריכה |
| **קוד לאתר** | קובץ JS אחד להטמעה. חד בכל גודל, שקיפות אמיתית, הכי קל |
| **PNG / SVG** | הפריים הנוכחי, כתמונה בודדת |

## איך מתחילים

הכלי הוא **קובץ HTML אחד**. אפשר פשוט ללחוץ על הקישור למעלה,
או להוריד את `index.html` ולפתוח אותו בדפדפן — הוא עובד גם בלי אינטרנט.

בצד ימין יש מדריך «איך מתחילים» בארבעה צעדים.

## שמירת העבודה

הסדרות וההגדרות נשמרות **בדפדפן שלך**, לא בקובץ.
כדי לשמור או להעביר למחשב אחר:

- **«הורד קובץ הגדרות»** — שומר את ההגדרות
- **«ייצא כלי עם ההגדרות שלי»** — שומר עותק של הכלי **עם** הסדרות בתוכו

## דרישות

דפדפן מודרני. כרום או אדג׳ מומלצים — הייצוא המדויק של הווידאו
משתמש ב‑WebCodecs, שקיים בהם.
